## הממשק

- **היום שלי:** דמות במראה תלת-ממדי, סיכום קלוריות ומאקרו וצ'אט Gemini.
- חצי הדמות הירוק מתמלא ביחס לתקציב הקלוריות (יעד + פעילות), והכחול ביחס ליעד המים. האחוזים יכולים לעבור 100%; המילוי החזותי נעצר ב-100%.
- טיפות זיעה מופיעות כשיש פעילות ביום הנבחר. זו המחשת התקדמות בלבד, לא מודל רפואי או הדמיה של השמנה.
- **יומן ומים:** ארוחות, אימונים, הוספה מהירה ומעקב מים. מאגר, סטטיסטיקה, יעדים והגדרות נשארים בטאבים נפרדים.
- בחירת היום משפיעה על הסיכומים והדמות. Gemini יכול לשייך כל אירוע לתאריך אחר, למשל "אתמול".
- APK גרסה 1.2 משאיר את כל התוכן מחוץ לשורת המצב, אזור המצלמה וסרגל הניווט, ומתאים את הגובה גם למקלדת. ב-Android 11 ומעלה נעשה שימוש ב-WindowInsets; בגרסאות קודמות נשמרת התאמת החלון של המערכת. באתר נעשה שימוש באזור הבטוח שמדווח הדפדפן.
- אפשר לרשום מים גם בצ'אט: "שתיתי חצי ליטר מים". כוס ללא נפח מפורש מחושבת כ-250 מ"ל; משקאות עם קלוריות נשמרים כמזון.

## מיקרופון צף

1. מגדירים או פותחים את מפתח Gemini בהגדרות.
2. לוחצים על הכפתור הירוק ומאשרים הרשאת מיקרופון. הכפתור הופך אדום בזמן ההקלטה.
3. לוחצים שוב לסיום, או מפסיקים לדבר. הטקסט הסופי מצורף לטיוטה הקיימת ונשלח ל-Gemini.
4. התאריך ללא ציון מפורש הוא היום שהיה נבחר בתחילת ההקלטה.

התמלול בעברית הוא Speech-to-Text, לא הקראה קולית של תשובות.
בדפדפן נדרש HTTPS ותמיכה ב-Web Speech API (מומלץ Chrome). ב-APK גרסה 1.1 ומעלה נעשה שימוש ב-SpeechRecognizer של Android; נדרש שירות דיבור מותקן ותמיכה בעברית.

עצירה מתבצעת אחרי כ-2.5 שניות ללא עדכון דיבור, כ-7 שניות ללא דיבור התחלתי או עד 60 שניות להקלטה. שירות הדיבור עשוי לעצור מוקדם יותר בעצמו. מעבר לרקע מבטל הקלטה ולא שולח טקסט.
שגיאה או תמלול לא סופי אינם נשלחים אוטומטית; הטקסט הזמין נשמר לבדיקה. ניתן תמיד לכתוב ידנית.

### פרטיות

האפליקציה אינה שומרת קובצי קול. שירות הדיבור של הדפדפן/Android עשוי להעביר קול לשירות הזיהוי שלו בהתאם להגדרות המכשיר. התמלול נשלח ל-Gemini רק לאחר סיום תקין; מפתח ה-API נשאר מוצפן מקומית, ונפתח בזיכרון בלבד. יומן ומזונות נשמרים במכשיר.

## פיתוח ופריסה

- אתר סטטי, ללא תלויות בנייה. בדיקות: `node --test`.
- בדיקת תחביר: `node --check app.js` ו-`node --check voice.js`.
- Android: JDK, Android SDK 35 ו-Gradle תואם ל-Android Gradle Plugin 8.9.1; מגדירים `ANDROID_HOME` ומריצים `gradle -p android assembleDebug`.
- בדיקת גבולות Android: `gradle -p android connectedDebugAndroidTest` עם מכשיר או אמולטור Android 11 ומעלה. הבדיקה מזריקה גבולות של שורת מצב, מצלמה, מקלדת וסיבוב מסך ובודקת את גבולות ה-WebView בפועל.
- APK נוצר תחת `android/app/build/outputs/apk/debug/app-debug.apk`. לפני פרסום, מעתיקים אותו ל-`CaloriTrack-debug.apk` בשורש הריפו. לעדכון ללא הסרת האפליקציה יש לשמור על אותו מפתח חתימת Debug.
- push ל-`main` מפעיל את GitHub Pages; רק קובצי האתר וה-APK מועלים לאתר.
- מעטפת Android טוענת את האתר החי. שינוי ממשק בלבד מתפרסם באתר; שינוי יכולות Android (כגון מיקרופון) דורש התקנת APK מעודכן.
